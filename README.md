# Cryptography and Network Security Project

## Project Overview

This project demonstrates basic cryptography, data integrity verification, risk assessment, and network security controls for a student records system.

## Project Structure

- `security_tool.py` - Python program for encryption, decryption, file verification, and SHA-256 integrity checking.
- `student_record.txt` - Sample student record used for testing.
- `student_record.encrypted` - Encrypted sample student record.
- `student_record_decrypted.txt` - Decrypted student record used for verification.
- `student_record.sha256` - Baseline SHA-256 hash used for integrity testing.
- `risk_assessment.md` - Security assets, vulnerabilities, risk rankings, and recommended controls.
- `README.md` - Project installation, execution, and testing instructions.

## Requirements

- Python 3
- Python `cryptography` package
